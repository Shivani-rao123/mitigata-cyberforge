What this does:

1. Runs the network agent against your target (nmap-based discovery).
2. For every web service it finds, automatically runs the web agent (crawl, admin/login detection, reflected-input testing).
3. For every downloadable binary the web agent finds, automatically runs the binary agent (hardcoded secrets, unsafe functions).

Every step is scope-checked before it touches the network — a target outside your authorized scope is blocked, not scanned.
