Pipeline

1  Network agent — nmap-based host/port/service discovery
2  Web agent — auto-triggered per web service found: crawl, admin/login detection, reflected-input testing
3  Binary agent — auto-triggered per downloadable binary found: hardcoded secrets, unsafe functions

Every step is scope-checked before it touches the network — a target outside your authorized scope is blocked, not scanned.
